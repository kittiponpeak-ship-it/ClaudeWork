June comes from the invoice/route file, whose coordinates were joined on cust code rather than on the branch: 120 of its 122 codes resolve to a single point, so all 321 rows under the Big C code sit on Big C (Pattaya Marina)'s coordinate. Those pins are moved onto the branch's own coordinate wherever the Jan/Mar master data knows it (switch Fix June coordinates off to see the file untouched); the rest stay flagged. The same join affects a smaller number of Jan/Mar rows — 23 coordinates carry two to five branch names each, marked shared coord. June also labels regions differently in the source (North/South/East…), so they are mapped onto the Jan/Mar names.
